## Overview

FAT32 Reader is a systems programming project that implements a complete FAT32 file system driver from scratch. Written in C, it provides low-level access to FAT32 volumes, enabling direct file and directory operations without relying on operating system APIs.

## Technical Details

This implementation handles the complexities of the FAT32 specification, including:

- **Boot Sector Parsing**: Reads and validates FAT32 boot sectors
- **FAT Table Navigation**: Traverses the File Allocation Table to locate file clusters
- **Directory Entry Processing**: Parses directory structures and long file names
- **Cluster Chain Management**: Follows cluster chains to read complete files

## File System Structure

The FAT32 file system layout:

## Technical Challenges

Building this project required deep understanding of:

1. **Binary Data Structures**: Working with little-endian byte ordering
2. **Pointer Arithmetic**: Efficient memory management in C
3. **Bit Manipulation**: Extracting FAT32 metadata from packed structures
4. **File System Specification**: Implementing the complete FAT32 spec
